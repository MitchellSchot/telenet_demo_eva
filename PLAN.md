# EVA demo roadmap

1. **Foundation (done)**: branded single-screen layout, story bar, all panels as empty placeholders, working .mp3/.mp4 upload and playback with Space/R shortcuts.
2. **Customer data**: fictional customer profile in the "Customer data" dashboard (products, billing, network usage, tNPS, case and sales history), kept in one fixtures module.
3. **Scripted call**: a 60-second timeline (transcript lines, per-turn text sentiment and voice emotion, EVA score) in a single script file.
4. **Synchronisation**: drive the story bar chapter, transcript bubbles, sentiment curve, emotion chips and flow-strip highlights from the audio's `currentTime`.
5. **Decision moment**: offer window moves red → amber → green; contrast "text-only bot: no offer" with "EVA: offer now"; Next best action card shows the live offer.
6. **Polish for recording**: subtle transitions, final copy pass, check at 1920×1080 and 1366×768.
